# 版式、风格与内容路由

脚本参数：`--layout` 取 `sticker3|person|food|three|compare`，`--style` 取 `sticker|bright|cream|street|dark`。

## 五套版式

| key | 名称 | 构图 | 适用 |
|---|---|---|---|
| `sticker3` | 贴纸人菜版（默认） | 菜品实拍大图铺满（顶部渐变虚化承载文字），人物贴纸压左下，大标题跳排置顶 | 菜谱、小吃、烘焙、快手菜等绝大多数美食内容 |
| `person` | 人物主体式 | 博主半身/特写占画面 55%~65%，标题走上方 1/3 留白 | 人设向："跟我一起吃""我在 xx 开店" |
| `food` | 菜品大特写式 | 菜品占 60% 以上位于视觉中心，标题走顶部 | 菜谱成品、单品种草 |
| `three` | 三分递进式 | 上=标题，中=人物或菜品，下=悬念/补充 | 探店、清单、测评 |
| `compare` | 对比拼贴式 | 上下二分，主标题压中间色带 | 翻车 vs 成功、进店前 vs 结账后、10 元 vs 100 元 |

`compare` 需要两张图时用 `--photo` + `--photo2`；只给一张则脚本自动取同一照片的不同垂直锚点。

## 五套风格

| key | 名称 | 色板 | 画面处理 | 适用 |
|---|---|---|---|---|
| `sticker` | 贴纸人气风（默认） | 深棕字 `#4A2A16` + 红强调 `#D9401E` + 黄油胶带 `#F7D14A` + 红气泡 `#E0492F`，全部粗白描边 | 菜品大图铺满、顶部渐变虚化、人物白边贴纸、放射线/爱心涂鸦 | 菜谱、小吃、烘焙、快手菜等绝大多数美食内容 |
| `bright` | 食欲明亮风 | 白字 + 黄强调 `#FFE04A` + 橙红色块 `#E8532B` | 暖光、高饱和、提亮 | 探店、家常菜、小吃 |
| `cream` | 奶油治愈风 | 深咖字 `#463525` + 焦糖强调 `#C9762F` + 米白底 `#FFF6E8` | 提亮、低对比、圆角色块 | 甜点、下午茶、烘焙 |
| `street` | 市井烟火风 | 米黄字 `#FFF6DC` + 红强调 `#FF4D4D` + 黑底 `#1A1A1A` | 压暗、高对比、高饱和 | 街边小吃、苍蝇馆子、夜宵 |
| `dark` | 高级暗调风 | 米白字 `#F4EFE7` + 金强调 `#C9A227` + 深黑 `#14100C` | 明显压暗、细衬线字体 | 咖啡馆、精致料理、酒庄 |

### sticker 风专属参数

- `--person 透明抠图.png`：RGBA 透明人物贴纸，自动加白描边+投影，压在菜品左下角；不给则纯菜品版。
- `--subtitle`：渲染为黄油色胶带笔刷（如「10分钟搞定」「零失败」）。
- `--badge`：渲染为红色对话气泡角标（如「快手美食」「家常菜」），放右侧中上避开人物。
- `--highlight "词1,词2"`：手动指定标题里换红色的菜名/主体词（数字与情绪词已自动换色）。
- `--person-h`：人物高度占画布比例，默认 0.52；人物过大遮挡菜品时下调。

## 内容子类型 → 版式 + 风格

| 子类型 | 版式 | 风格 | 备注 |
|---|---|---|---|
| 菜谱 / 快手菜 / 烘焙甜点 / 地方小吃 | `sticker3` | `sticker` | 有透明抠图必须传 `--person`；菜名走 `--highlight` |
| 探店（有出镜） | `three` | `street` / `bright` | 人均价、店龄走角标 |
| 探店（无人物/纯菜品图） | `food` | `bright` | — |
| 减脂餐 | `three` | `cream` | 禁写功效词，只写食材与做法 |
| 食材测评 / 零食合集 | `compare` | `bright` / `street` | 天然适合对比拼贴 |
| 咖啡馆 / 精致料理 | `person` / `food` | `dark` | 留白要更足 |

## 标题钩子改写规则

允许在用户原标题基础上做轻量润色（补悬念、补数字、把长句压到 12 字内）。

**禁止**：篡改原意；凭空添加用户未提供的人均价、店名、时长、排名、功效等事实。缺信息时宁可留空，也不要编。

优先保留的钩子要素：数字（步数/分钟/人均）、地点（城市/巷子/老店）、情绪词（绝了/避雷/翻车）。脚本会自动把这些要素换色强调。
