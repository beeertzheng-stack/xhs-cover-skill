# 小红书美食封面 · 硬性规范表

生成时不可违反；`scripts/check_output.py` 会按本表逐项自动校验。

## 画布与文件

| 项 | 规定 | 校验 |
|---|---|---|
| 比例 | 严格 3:4 竖版 | 误差 ≤0.002 |
| 首选尺寸 | 1242×1656 | 推荐值 |
| 兼容尺寸 | 1080×1440 | 推荐值 |
| 禁止 | 1:1、横版作为默认输出 | 直接拒绝 |
| 宽度下限 | ≥1080px | 硬性 |
| 格式 | PNG（优先）/ JPG | — |
| 色彩 | sRGB，嵌入 ICC | 检测 icc_profile |
| 文件大小 | ≤5MB | 硬性 |
| 配套内页图 | 比例必须与封面一致 | 人工确认 |

## 安全区（基准 1080 宽，按比例缩放）

| 边 | 最小留白 |
|---|---|
| 左右 | 80px |
| 顶部 | 150px（避开平台顶部导航） |
| 底部 | 200px（避开头像/点赞栏/标题遮挡区） |

核心主体（人脸、菜品、标题文字）全部落在画面中部约 65% 区域内。

## 文字渲染

| 项 | 规定 |
|---|---|
| 主标题 | ≤12 字，最多 2 行，单行 ≤8 字 |
| 全文总字数 | 标题+副标题+角标 ≤20 字 |
| 主标题字号 | 60~80px（1080 基准）；贴纸人气风用 96~132px 大标题，脚本自适应 |
| 副标题字号 | 32~44px（sticker 胶带笔刷约 46px） |
| 角标字号 | 24~32px（sticker 气泡约 44px） |
| 行距 | 1.4~1.5 倍 |
| 字重 | 主标题加粗，允许描边/投影/纯色底衬 |
| 承载面 | 文字必须压在低纹理区域（纯色底、虚化区、暗化蒙层），禁止直接压人脸或菜品细节 |
| 关键词强调 | 数字、地点、价格、情绪词单独换色（脚本自动识别） |

## 视觉纪律

- 一屏主要颜色 ≤3 组
- 贴纸/emoji/手绘线条 ≤2 组
- 留白 ≥15%
- 主体优先级：人脸 > 菜品 > 装饰元素；装饰不得抢主体

## 出图自检清单（任一不过即重做）

1. 比例严格 3:4，尺寸 1242×1656 或 1080×1440
2. 文件 ≤5MB、sRGB、宽度 ≥1080px、无明显压缩糊图
3. 主标题 ≤12 字、≤2 行、无错别字、无乱码字
4. 文字全部在安全区内，未被平台 UI 遮挡
5. 人脸完整无变形、五官与原照片一致
6. 菜品为主体且有食欲感，无 AI 结构性破绽
7. 颜色 ≤3 组、装饰 ≤2 组、留白 ≥15%
8. 无违禁词、无功效暗示、无引流标识、无版权风险元素
9. 缩略图（手机信息流小图尺寸）下标题仍可读

## 字体合规

只使用无版权/可商用字体，本机可用（按优先级）：

| 用途 | 字体 | 许可 |
|---|---|---|
| 主标题（贴纸人气风，默认） | 站酷快乐体 / 汉仪粗圆（圆头手写感 + 粗白描边） | 免费商用 |
| 主标题 | 阿里巴巴普惠体 3（75/85/95 字重） | 免费商用 |
| 主标题（市井风） | 站酷酷黑 / 站酷高端黑 / 站酷快乐体 | 免费商用 |
| 主标题（暗调风） | 思源宋体 Bold/SemiBold/Black | OFL 开源 |
| 副标题/角标 | 思源黑体 / 阿里巴巴普惠体 | OFL / 免费商用 |

禁止使用受版权保护的商业字体（方正、汉仪收费系列等）与未授权 IP 形象。
