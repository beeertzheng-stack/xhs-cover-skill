# 小红书美食封面生成器 · xhs-cover-skill

一个可直接放进 AI Agent 技能目录（或独立当命令行工具用）的小红书美食封面生成技能：
**输入「标题文案 + 照片」，输出一张合规、可提升信息流点击率的 3:4 竖版封面 PNG。**

> 核心原则：画面文字**一律由脚本用可商用开源字体确定性渲染**，绝不交给 AI 生图写字——
> 从根源上避免乱码、错字、压脸、越出平台安全区。

---

## ✨ 能力概览

| 维度 | 内容 |
|---|---|
| 输出规格 | 严格 3:4 竖版，默认 1242×1656（兼容 1080×1440），PNG + 内嵌 sRGB ICC，≤5MB |
| 版式 | 5 套：`sticker3` 贴纸人菜（默认）· `person` 人物主体 · `food` 菜品大特写 · `three` 三分递进 · `compare` 对比拼贴 |
| 风格 | 5 套：`sticker` 贴纸人气（默认）· `bright` 食欲明亮 · `cream` 奶油治愈 · `street` 市井烟火 · `dark` 高级暗调 |
| 智能路由 | 按内容子类型（探店 / 菜谱 / 减脂 / 烘焙 / 小吃 / 测评 / 合集 / 咖啡馆）自动选版式 + 风格 |
| 合规拦截 | 广告法绝对化用语、功效暗示词、伪造荣誉与引流标识，在生成前与交付后各拦截一次 |
| 交付前自检 | 13 项自动校验（比例 / 尺寸 / 宽度 / 体积 / 色彩 / 字数 / 行数 / 安全区 / 违禁词 / 缩略图可读性） |

### 默认「贴纸人气风」长什么样

参照小红书爆款美食封面拆出的设计语言，全部由脚本绘制：

- **圆头手写大字**（站酷快乐体）：深棕 + 红橙双色、粗白描边、柔和投影、两行交错倾斜跳排，字号最大到 132px
- **黄油色胶带笔刷**承载副标题（如「10 分钟搞定」）
- **红色对话气泡**承载角标（如「快手美食」「人均 38」）
- **人物贴纸**：透明抠图自动加白色描边 + 投影，压在菜品左下角
- **涂鸦点缀**：黄色放射短线 + 小爱心，硬约束在 2 组以内，不抢主体
- **菜品大图铺满**整屏，只把顶部约 1/3 渐变虚化作为文字的低纹理承载面

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

只依赖 Pillow（无重模型、无网络调用、纯本地运行）。

### 2. 准备字体（关键）

脚本按优先级在本机字体目录里查找**可商用 / 开源**字体。缺失时会自动降级，但默认贴纸风效果依赖圆头手写体：

| 用途 | 首选字体 | 许可 |
|---|---|---|
| 贴纸风主标题 | 站酷快乐体 | 免费商用 |
| 常规主标题 | 阿里巴巴普惠体 3（75/85/95 字重） | 免费商用 |
| 副标题 / 角标 | 思源黑体、阿里巴巴普惠体 | OFL / 免费商用 |
| 暗调风主标题 | 思源宋体 Bold / SemiBold | OFL |

> ⚠️ 请勿替换为方正、汉仪收费系列等受版权保护的商业字体。

### 3. 生成封面

```bash
python3 scripts/compose_cover.py \
  --photo 菜品照片.jpg \
  --person 透明抠图.png \
  --title "番茄肥牛拌面" \
  --subtitle "10分钟搞定" \
  --badge "快手美食" \
  --highlight "肥牛" \
  --layout sticker3 --style sticker \
  --size 1242x1656 \
  --out 封面.png
```

脚本会同时产出 `封面.report.json`，内含每个文字框的真实坐标，供校验与复查。

### 4. 交付前校验（必做）

```bash
python3 scripts/check_output.py 封面.png
```

退出码：`0` 全部通过 · `1` 存在硬性不通过项（必须改文案或调参数后重生成）· `2` 仅告警（需目视确认）。

## 🎛️ 参数速查

| 参数 | 说明 |
|---|---|
| `--photo` | 必填。菜品 / 场景照片，建议宽度 ≥1080px |
| `--person` | 透明底 RGBA PNG 人物抠图。`sticker` 风会渲染成白边贴纸压在菜品左下角 |
| `--photo2` | `compare` 版式下半图；不给则自动取同一照片的不同垂直锚点 |
| `--title` | 主标题，≤12 字、≤2 行、单行 ≤8 字（超限直接报错终止） |
| `--subtitle` | 副标题；`sticker` 风渲染为胶带笔刷，其余风格走底部色带 |
| `--badge` | 角标；`sticker` 风渲染为红色对话气泡，其余风格走胶囊标签 |
| `--highlight` | 额外换色强调词，逗号分隔（数字、时长、价格、情绪词已自动识别） |
| `--layout` / `--style` | 见上方版式与风格表 |
| `--size` | 默认 `1242x1656`；素材分辨率低时用 `1080x1440` |
| `--person-h` | 贴纸风人物高度占画布比例，默认 0.52；人物挡住菜品时下调 |
| `--subject-fill` | 覆盖主体框高度占比（0.4~0.95） |
| `--jpeg` | 额外另存一份 JPG |
| `--report` | 文字框坐标报告输出路径，默认 `<out>.report.json` |

## 🛡️ 内置合规红线

1. **文案**：命中绝对化用语（最好吃 / 第一 / 顶级 / 100%…）、功效暗示（减肥 / 降糖 / 排毒 / 抗癌…）、伪造荣誉（米其林推荐 / 央视推荐…）、引流标识（微信 / 二维码…）→ 生成前直接终止。
2. **不编造事实**：缺人均价、店名、时长、排名等信息时宁可留空，禁止凭空补。
3. **平台安全区**：左右 ≥80px、顶部 ≥150px、底部 ≥200px（按 1080 基准缩放），头像 / 点赞栏 / 顶部导航遮挡区一律避开。
4. **视觉纪律**：一屏主色 ≤3 组、贴纸与手绘线条 ≤2 组、留白 ≥15%、主体优先级 人脸 > 菜品 > 装饰。
5. **字体版权**：只使用免费商用 / OFL 开源字体。

违禁词表可在 `references/banned-words.txt` 中按品类自行扩充，两个脚本共用同一份。

## 🤖 在 Agent 中使用

把整个目录放进你的 Agent 技能目录即可。`SKILL.md` 的 frontmatter 声明了触发条件、允许使用的工具与分步执行流程：
校验输入 → 判定内容子类型并路由 → 文案合规定稿 →（可选）画面增强 → 合成 → 自动校验 → 目视自检 → 交付。

纯命令行场景可以完全忽略 `SKILL.md`，直接用上面第 3、4 步。
